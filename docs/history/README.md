# Historical engineering records

These files preserve dated investigations, review prompts, maintenance reports,
and benchmark snapshots. They are not part of the supported build workflow and
must not be used as current release status.

For current guidance, read:

- [Current status](../CURRENT_STATUS.md)
- [Development and validation](../DEVELOPMENT.md)
- [Architecture](../ARCHITECTURE.md)
- [Release policy](../RELEASE.md)

Git history remains the authoritative record of superseded implementation
details. New one-off investigation notes should be temporary unless they contain
durable evidence worth preserving here.
